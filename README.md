A simple python backend program that allows you interact with a cinema based application through your terminal

A simple backend python project that gives you an experience of
a cinema application that allows you to view movies available and also be able to
create tickets with unique ticket ids but only if you are a registered user on my database
but user data is protected because your password and sensitive information are hashed
and provided the database is in anyway compromised your data would still be secure in
the sense that it is hashed and the hacker has to find out the particular hash format I
used.

You will need to have MYSQL running at all times which you can do with xampp or zampp(Either one of your choosing)
